# Using Astro as a Static Site Generator

## Setup
```
cd ssg-exericse
npm install
```

## Build
```
npm run build
```
HTML files will be generated in `dist/`

## Preview Locally
```
npm run dev
```
Visit these pages:
Home: http://localhost:4321/
About: http://localhost:4321/about/
Contact: http://localhost:4321/contact/
